# Robotics Journal: Mechatronics and Robotics, one project at a time

My 1-year roadmap to think and build like Tony Stark: electronics, mechanics, control, software, AI and product thinking.
Every month: **learn the theory, build one thing, write down what I learned and what broke.**

**Started:** 2026-11-07  |  **Author:** Pranjal

## Map of this repo

| Folder | What lives there |
|---|---|
| `phase-0-foundations` ... `phase-4-capstone` | Month-by-month project folders (README, circuit, code, cad, media) |
| `math-theory/` | Math + physics track, notes and solved problems |
| `side-tracks/` | PLC, KiCad, power electronics, mechanical depth, etc. |
| `logs/` | Weekly logs (`python tools/new_log.py`) |
| `notebook/` | Build-notebook scans/entries |
| `project-backlog/` | Extra project ideas |
| `certificates/` | NPTEL / Coursera / badges |
| `competitions-and-internships/`, `portfolio/` | Resume fuel |
| `year-2-and-beyond/` | Specialization tracks |
| `docs/`, `templates/` | Rules, resources, gates, templates |

See [PROGRESS.md](PROGRESS.md), [SAFETY.md](SAFETY.md), [FIRST-7-DAYS.md](FIRST-7-DAYS.md) and [docs/rules-and-learning-loop.md](docs/rules-and-learning-loop.md).

## Roadmap

| Phase | Months | Builds |
|---|---|---|
| 0 | Weeks 1-4 | Measured circuit |
| 1 | 1-3 | Arc reactor lamp, posture buddy, obstacle car, Mark I robot |

## Weekly habit
Run `python tools/new_log.py`, fill it in, commit, push. Small commits, clear messages (`month-02: posture buddy IMU threshold tuned`).
