# The five rules + learning loop

## Learning loop (use for every topic)
1. **Why** - what physical law or maths makes this work?
2. **Model** - write an equation or block diagram before touching hardware.
3. **Build** - the smallest working version.
4. **Measure and break** - verify the model, then push it until it fails.
5. **Write** - half-page log in your own words, with a photo, pushed to GitHub.

## Five rules
1. Read the datasheet of every part you use.
2. Never paste code you cannot explain line by line.
3. One project = one README, circuit diagram, code and a short video.
4. Every project gets one deliberate failure test.
5. Safety first (see SAFETY.md).

## Weekly rhythm (~10-12 h)
- 4 weekdays x 1.5-2 h learning
- 2 weekend sessions x 3-4 h building
- 1 short session: review, log, plan next week
- Exam weeks: learning only. **Do not drop the log.**
