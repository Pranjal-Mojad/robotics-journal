# Gates before moving on

- After month 3: read a datasheet and wire any sensor on your own.
- After month 7: tune a PID without guessing.
- After month 10: explain every node in your ROS 2 graph.

# Expert checklist (years 2-5): each item needs proof

| Competency | Proof | Done |
|---|---|---|
| Design a mechanism in CAD, simulate and manufacture it | Printed/machined assembly with drawings | [ ] |
| Design and assemble a PCB (MCU + motor driver + sensors) | Photos, schematic, Gerbers | [ ] |
| Write real-time firmware without a library crutch | Timer/interrupt-based control loop + tests | [ ] |
| Derive + implement FK/IK and dynamics for a new robot | Code, derivation notes, working arm | [ ] |
| Design a controller, justify gains, show stability margins | Bode plots, step responses, hardware test | [ ] |
| Build a Kalman filter for real noisy sensors | Logged data vs filter output | [ ] |
| Run a full ROS 2 navigation or manipulation stack | Demo video + launch files | [ ] |
| Use vision or learning for a real perception task | Dataset, model, accuracy, failure cases | [ ] |
| Read a research paper and reproduce its result | Reproduction repo + one-page review | [ ] |
| Explain every design decision in writing and aloud | Blog posts, talks or demo walkthrough | [ ] |
